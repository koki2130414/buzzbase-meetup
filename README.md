# BUZZBASE MEETUP VOL.03 — 告知サイト

完全招待制イベント **BUZZBASE MEETUP VOL.03** の告知サイトです。
`index.html` 1ファイルで完結しており、GitHub Pages でそのまま配信しています。

## 限定公開について

- すべてのページに `noindex, nofollow` を指定しています
- `robots.txt` で全クローラーを拒否しています
- どこからもリンクしていないため、**URL を知っている人だけ**が閲覧できます

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | サイト本体（HTML / CSS / JS / 画像をすべて内包） |
| `robots.txt` | 検索エンジン除け |

ページ遷移は `#/numbers` のようなハッシュルーティングで行っています。

## 更新方法

`index.html` を差し替えてコミットすると、数十秒〜数分で公開サイトに反映されます。

## 掲載内容について

現在、一部のクルー情報・過去開催の写真・参加者コメント・協賛ロゴは**仮データ**です。
公開前に実際の内容へ差し替えてください。
